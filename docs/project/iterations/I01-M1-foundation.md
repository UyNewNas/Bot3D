## 3. 首轮测试数据

以下是人工 UNIT / MOCK 数据，不是设备参数或安全阈值。实现时固化为可审阅 fixture，使用独立手算预期，不用被测函数生成期望值；变更需在 AR 中说明。

- 标识：robot 用 `arm-fixture`，device 用 `mock-device-a`，frame 用 `cell/world` 与 `arm-fixture/base`，tool 用 `tool0`；只读镜像可指同一 device，但无执行端口。空 ID、无作用域 frame、错误维度为非法样本。
- 单位：1 m＝1000 mm、π rad＝180° 只验证显式边界换算；领域目标始终为 m / rad，不静默猜测裸输入单位。有效点示例 `[0.3, 0.05, 0.25]`，未知值保持未知。
- 变换：T_A_B 的旋转为绕 z 轴 +π/2，平移 `[1, 2, 3]` m。B 原点映到 `[1, 2, 3]`，点 `[1, 0, 0]` 映到 `[1, 3, 3]`；方向 x 映 y、y 映 -x、z 不变（方向不加平移）；逆变换还原原点和该点。
- 姿态：单位姿态 `[0, 0, 0, 1]`，绕 z 轴 +π/2 为 `[0, 0, √0.5, √0.5]`（xyzw）；q 和 -q 的旋转相同。浮点比较绝对误差 1e-9，四元数范数允许偏差 1e-6，并覆盖边界两侧；零范数、长度错误、明显非单位范数、NaN、±Infinity 均拒绝。
- 时钟：虚拟单调钟从 0 s 开始，可显式推进；与独立仿真源钟分开，不靠真实睡眠。I01 只检查时钟端口和类型，租约 / 期限边界留后续实现测试。
- 能力：依次缺少规划、模型、坐标、策略或执行支持，检查不可用原因与能力版本；可用组合只在纯组合函数的人工输入中测试。对外只读 mock 永远无执行支持，不因测试 fixture 打开执行入口。
