## 设计交付

[运行时详细设计](../../design/05-runtime-coordination.md) 定义既有命令状态、结果确定性及业务槽、物理执行锁和当前运动之间的关系。设计涵盖接受、意图、最终应用下发裁决和外部受理的顺序，以及撤销、取消、STOP 和超时。最终应用裁决之后、实际调用之前仍可能发生抢占，迟到写入须通过写入屏障、再次停止、新鲜停车证据和审计处理。设备端隔离仍需适配器证据。

恢复设计要求启动时不重放任务，通过原句柄对账，分别核实历史结果、当前停车和旧执行者是否仍能写入，再按可审计条件决定解锁。设计同时锁定等值到期、执行预算起点以及异步写入后的前置条件复核。公共命令状态沿用既有契约。
