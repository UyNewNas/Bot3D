# DEV-M1-12：状态投影、时间质量与静止证据

本工作包落实 [状态契约](03-contracts-and-adapters.md#6-状态与事件) 与 [I02](../project/iterations/I02-M1-control-loop.md) 的 T06 切片。StateProjection 是由未来机器人协调序列单独持有的同步内存对象；接受不可变反馈和显式保护钟读数，不连接设备，不发布命令结果，不自动激活，也不将停车证据解释成旧执行者已经失效。

## 1. 边界与数据

`domain/projection.py` 定义配置、上下文、反馈、时钟映射和不可变快照；`application/state_projection.py` 负责顺序采纳、质量、目标 / 计划引用及静止窗口。依赖仅指向既有领域基础和只读身份，不要求控制权或日志实现。旧 Registry API 保持原语义。

每个投影固定一个 robot、完整 BackendIdentity、source_id、源 clock_id、保护 clock_id、关节顺序、坐标系、工具及可信来源。SIM 配置使用 SIMULATED，REAL 使用 MEASURED；DERIVED 不能作为关节 / 控制器停车依据。部署方必须提供全部新鲜度、时钟不确定度、速度、位移、窗口和采样间隙参数；没有设备默认安全值。

反馈以完整包更新 joints、tool_pose、controller 三类数据。某一类缺失即明确 None / INVALID，不从上个包补成“当前值”；关节内部未知值仍是 None。三类分别保留来源、质量、原因和有效期限。实际控制模式、急停与保护停止状态可为未知，不默认为安全。readiness、租约、ARMED、任务生命周期及未结执行仍由各自所有者维护，后续协调器组合总快照。

`ProjectionContext` 保存能力、模型、场景与标定版本。显式上下文更新清除目标 / 计划和静止窗口，旧实际数据保留但 INVALID；采纳代数同时失效，即使上下文 A→B→A 也只能由新的更高序号反馈恢复，不能复活旧值或旧 FK。新目标清除旧计划；计划引用必须属于当前目标与上下文。目标 / 计划操作不写 actual。投影不生成轨迹或判断命令成功。

## 2. 时间与质量

`ClockMapping` 是可信服务内部提供的偏移区间，包含源 clock_id、保护钟有效窗口、offset_ns、uncertainty_ns 和 revision。保护时间区间为 `[source_tick + offset - uncertainty, source_tick + offset + uncertainty]`。有效窗口是半开区间，必须覆盖完整采样区间、原接收时刻与当前观察时刻；只在接收时有效不能替代采样时有效。超过配置不确定度或没有映射时为 UNSYNCED。源钟与保护钟相同时直接用零偏移 / 零不确定度，不接受伪造偏移。

- 源年龄取 `now - 最早可能采样时刻`，即最保守的年龄上界；接收年龄取 `now - 被采纳包的 received_at`。二者独立，任一达到配置上限即 STALE。
- 源时间区间必须非负且不晚于原接收时刻；确定未来为 INVALID，不能排除未来为 UNSYNCED。映射不能将原先迟到的数据当成新采样。
- FRESH 的有效期限取源年龄截止、原接收截止和映射截止的最小值；轮询不重新起算 TTL。
- 映射更新后旧包不重新解释。恢复使用新映射要求源时间严格超过更新时保留的源时间水位；更高序号但相同源时刻继续使用旧约束并保持 UNSYNCED，中间缺时间的包也不重置水位。
- 另外保留最近匹配包的 transport 接收时刻 / 年龄，用于展示“持续收到旧数据”；它不能代替 actual 的两个年龄。
- 保护钟换域或回退锁定为 INVALID；源钟换域锁定为 UNSYNCED。重新绑定 / 新 epoch 需建立新投影，旧值不能自动恢复。

质量优先级为已锁定错误 / 输入无效、缺少可信同步、陈旧、FRESH。无数据仍为 INVALID。质量变化保留原因；不把来源相同当作身份和时间验证。

## 3. 顺序规则

| 输入 | 处理 |
| --- | --- |
| 身份 / source_id 不匹配 | 拒绝，不污染当前实际状态 |
| 上下文不匹配 | 拒绝，不让迟到旧上下文覆盖当前状态 |
| source_seq 更小 | 通常为 OUT_OF_ORDER；保留当前包及其原接收时刻。若该序号仍属于当前有效静止窗口且与保留的原包矛盾，优先按 CONFLICT 锁定 INVALID |
| source_seq 相同、除 received_at 外内容相同 | DUPLICATE；仅更新 transport 接收信息，不刷新源 / actual 接收年龄，不延长静止窗口 |
| source_seq 相同、内容不同 | CONFLICT；锁定 INVALID，不能挑选对停车有利的版本 |
| 序号增加、源时间回退 | SOURCE_REGRESSION；锁定 INVALID |
| 序号增加、源时间相同 | 可以显示新内容，源年龄不变，重新开始静止窗口 |
| 序号跳跃 | 采纳最新包，但静止窗口重新开始，不能假设丢失期间没有运动 |

`state_seq` 在可观察投影内容或质量变化时增加；单纯年龄随查询时间增长不增加。transport 信息变化可以增加 state_seq，不能将它当成源采样序号。它不兼任事件游标；订阅 / 游标一致性由 DEV-M1-15 实现。

## 4. 静止与 FK

STOPPED 需要配置可信来源的 FRESH 控制器 STOPPED，以及名称 / 顺序完全匹配且位置、速度均已知的 FRESH 关节。每个速度绝对值不超过阈值，整个窗口内每个关节的最大位置减最小位置不超过位移阈值；源序号连续、源时间严格前进，源区间与接收间隙均不超过配置上限。窗口的保证持续时间为最后源时间区间下界减首个区间上界，达到 stationary_window_ns 才成立。轮询、重复包、单个 STOPPED 包和停止回执都不能延长窗口。

缺失、陈旧、失步、输入错误、上下文变化、采样断层、静止检查重启或可信运动都会清窗口。可信控制器 MOVING、速度超限或窗口位置变化超限可显示 MOVING；没有完整可信停车证据则为 UNKNOWN。

窗口保留能覆盖保证时长的最短已观测后缀，以及其中每个原始包，用于检测窗口内部迟到矛盾。保留首样本之前的普通旧包不改写当前证据。位置范围按整个保留窗口核对，不只比较相邻两包。最大采样间隙约束窗口中相邻采样；窗口末样本之后的证据有效期由明确的源 / 接收新鲜度控制，证据没有声称覆盖尚未采样的未来时刻。

`begin_stationary_check(not_before, now)` 建立新的观察轮次并清窗口。之后的采样区间下界必须不早于 not_before，避免“STOP 前采样、STOP 后到达”的包证明该轮停车。证据包含原绑定、来源、上下文、首尾源序号、首尾源时刻、映射后的首区间上下界 / 末区间下界及最后接收时刻；后续 STOP / writer barrier 用例仍须再核验时间、身份和该轮依据。

`apply_fk` 只采纳匹配当前绑定、上下文、source_id、源序号与工具 / 坐标的 FK 结果；来源强制为 DERIVED，保留原关节采样 / 接收时间和质量，不因计算完成而刷新年龄。同一后端上两个源恰好相同的序号不能互用 FK。直接提供 DERIVED `PoseFeedback` 则明确声明其依据是同包关节；该路径同样继承关节质量，不覆盖更严重的位姿自身错误。不实现模型求解器，也不允许 FK 替代停车的控制器 / 关节证据。

当前内存实现按窗口内样本数复制 / 检查保留事实并计算关节范围；尚无高频吞吐或固定执行时长承诺。窗口会滚动淘汰过早样本，但容量 / 背压与受控延迟仍由 DEV-M1-16 验证。该限制不允许省略当前停车证明所依赖的冲突检查。

## 5. 本轮固定 fixture 与验证

人工 fixture 使用 control-clock / source-clock，offset=0 ns、uncertainty=0 ns、映射有效窗口 `[0, 1000)`；source / receive 最大年龄 30 / 20 ns，允许不确定度 2 ns；静止窗口 10 ns、最大采样间隙 6 ns、速度阈值 0.01 rad/s、全窗口位移阈值 0.001 rad；两个命名关节、SIMULATED 来源。它们仅用于可重复边界测试，不是运行设备参数。

| 切片 | 证据 |
| --- | --- |
| T06/projection | 目标 / 计划 / 实际分离；未知与 per-class 来源；上下文、身份、关节、工具 / 坐标校验；FK 不冒充测量 |
| T06/order | 乱序、相同 / 冲突重复、相同源时刻、跳号、换钟与源回退；持续收包不续鲜；不可变旧快照 |
| T42/feedback-clock | 双年龄、延迟、半开边界、偏移 / 不确定度、映射失效、未来时间、保护钟错误与变换后旧包 |
| T10/stationary | 单包 / 重复 / 轮询不停车，完整窗口、速度 / 位移、缺失 / 陈旧 / 不可信、间隙、停止轮次后采样与上下文重建 |

本轮不关闭 T10 的物理 STOP、T11 的执行锁、T27 的完成或 T42 的命令预算；完整协调链由 DEV-M1-07 / 08 / 09 继续。技术结果只依据当轮 AR，产品验收保持 PENDING。
